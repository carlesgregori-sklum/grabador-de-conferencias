GRABADOR DE CONFERENCIAS — GUÍA RÁPIDA
========================================

No necesitas instalar nada ni añadir extensiones.
Requiere Windows 10 build 20348 o posterior y Google Chrome.

1. Conserva completa esta carpeta; no muevas únicamente el ejecutable.
2. Abre Chrome y prepara la conferencia o el caso de Bizneo.
3. Haz doble clic en "Grabador de conferencias.exe".
4. Comprueba que el estado indique "Chrome listo".
5. Elige qué quieres grabar:
   - Pantalla completa: comienza directamente con la pantalla principal.
   - Elegir pantalla: selecciona un monitor completo en Chrome.
   - Pestaña de Chrome: elige la pestaña y activa "Compartir también el audio".
6. Activa "Incluir micrófono" solo si también quieres grabar tu voz.
7. Revisa la calidad y usa "Cambiar" si quieres otra carpeta de destino.
8. Pulsa el botón coral. La ventana se minimizará cuando comience.
9. Para terminar, vuelve desde la barra de tareas y pulsa "Finalizar y guardar".

DESTINO INICIAL
Vídeos\Grabador de conferencias

AUDIO
- Pantalla completa o monitor: audio de todo el árbol de Chrome.
- Pestaña: únicamente el audio compartido por la pestaña elegida.
- Micrófono: únicamente si activas expresamente la opción.

PRIVACIDAD
No graba el audio de otras aplicaciones, no envía datos a Internet y no
necesita ninguna extensión. El selector auxiliar se comunica solo con la
aplicación local mediante 127.0.0.1.

CALIDAD
- Full HD 1080p · 30 FPS: opción inicial recomendada.
- HD 720p: archivo más ligero.
- 60 FPS: movimiento más fluido, con mayor consumo de CPU y espacio.

IMPORTANTE
Finaliza siempre desde la aplicación para que el MP4 se cierre correctamente.
Si quedan archivos temporales, consérvalos: pueden permitir recuperar el vídeo
o el audio.

SMARTSCREEN
El ejecutable no tiene una firma comercial. Usa "Más información > Ejecutar de
todas formas" únicamente si confías en el ZIP recibido.
